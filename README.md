# MskDSPPlatform

MskDSP 的服务端平台，面向上位机、下位机和后续网页管理端提供统一的服务能力。

## 规划范围

- 现场和设备管理
- 诊断信息与日志接收
- 上下位机软件更新
- 设备运行状态和数据上报
- 用户权限与操作审计
- 网页管理接口

## 相关仓库

- `MskDSPUpper`：Windows 上位机
- `mskdsp`：Linux 下位机
- `MskDSPProto`：上下位机及平台共用的 Protocol Buffers 定义

## 当前状态

仓库当前只建立基础结构。后续先实现最小 gRPC 服务端和诊断包上传闭环，再逐步增加存储、认证和网页管理功能。

## 开发原则

- 上位机与平台之间使用带 TLS 的 gRPC 通信。
- 大文件使用流式上传，并在服务端校验 SHA256。
- 现场日志和配置中的敏感信息必须脱敏。
- 运行数据、诊断文件和网页管理接口按功能模块拆分。

# 平台账号管理与上位机登录

## 使用流程与边界

管理员在 Web `/accounts` 添加用户名、密码和显示名称，上位机以后使用该用户名和密码登录平台。管理员可修改显示名称、启禁用账号及重置密码。用户名创建后不再修改，平台自动维护内部编号，用户无需登记安装实例、填写现场编号或手动签发令牌。当前仅建设平台，未修改上位机，也未提供远程业务操作。

现有管理员 `/login` 和配置中的管理员账号继续负责 Web 管理；本页创建的是上位机使用的普通账号，不能获得点表、软件发布或平台更新权限，也不能登录 Web 管理界面。普通账号与管理员身份、会话分别管理，禁止创建与当前管理员同名的普通账号。

## 数据与账号规则

账号保存于平台业务数据目录的 `accounts/accounts.sqlite3`。开发默认 `data/accounts/accounts.sqlite3`；服务器按现有持久化挂载解析数据目录，程序更新和容器重建时保留。数据库只保存随机盐 Argon2id 密码哈希，不保存明文密码，不提供密码查询；日志和管理响应均不包含密码或哈希。

用户名去除首尾空白并统一为 ASCII 小写，长度 3～64 字节，仅允许字母、数字、下划线、点和横线；用户名唯一。密码为 8～128 UTF-8 字节且不能全为空白，登录不修剪密码。显示名称默认用户名，为 1～128 UTF-8 字节且不含控制字符。最多 10000 个普通账号。修改使用 revision，旧版本返回 409，防止覆盖其他窗口的修改。

启禁用和重置密码递增账号认证版本，全部旧登录会话失效，重新启用不会恢复旧会话。用户名/密码错误、未知或禁用账号均返回相同登录错误。数据库故障拒绝登录，不回退为匿名接入。

## 管理接口

管理接口仅接受现有管理员 Cookie。写请求要求 `Content-Type: application/json`、`X-MskDSP-Action: account`，并校验 Origin 与 Host 同源。请求体上限 8 KiB。记录包含 id、username、display_name、enabled、revision、created_at、updated_at、last_login_at、online_connections，不包含密码。

| 接口 | 请求 / 响应 |
| --- | --- |
| `GET /api/v1/accounts` | 账号列表 |
| `POST /api/v1/accounts` | `{username,password,display_name}`；201 账号详情 |
| `GET /api/v1/accounts/{id}` | 账号详情 |
| `PUT /api/v1/accounts/{id}` | `{revision,display_name,enabled}`；账号详情 |
| `POST /api/v1/accounts/{id}/password` | `{revision,password}`；重置后的账号详情 |

错误为 JSON `{error}`，400 字段错误、401 未登录、403 来源或权限不合法、404 账号不存在、409 用户名重复或修改版本冲突、500 存储错误。旧 `/agents` 页面跳转到账号管理；旧 `/api/v1/agents` 接口移除。

## 上位机登录接口

登录和退出写请求要求 `Content-Type: application/json`、`X-MskDSP-Action: client-auth`，有 Origin 时同源校验，不开放 CORS。客户端认证仅接受 Bearer 会话，不使用管理员 Cookie。

| 接口 | 请求 / 响应 |
| --- | --- |
| `POST /api/v1/client/auth/login` | `{username,password}`；返回 `{access_token,token_type:"Bearer",expires_in,account}` |
| `GET /api/v1/client/auth/me` | `Authorization: Bearer <access_token>`；返回 `{account,expires_in}` |
| `POST /api/v1/client/auth/logout` | 同上；撤销当前会话，重复退出幂等返回 204 |

access_token 是登录后供程序自动携带的会话，不需要用户手动管理或填写。仅保存于平台内存，默认 8 小时有效（沿用 auth.session_seconds），平台重启、退出、禁用或重置密码后失效。登录尝试全局每分钟最多 10 次，密码校验最多 2 个并发；过载返回 429，数据库不可用返回 503。最多 1024 个登录会话，每个账号最多 16 个。

上位机登录后使用该会话调用 gRPC `AgentService.ConnectAgent`。Hello 的 agent_id 可由客户端自动生成并保存，不填写时平台自动分配；同账号多台电脑可同时接入，同账号同实例不覆盖旧连接，不同账号的实例编号互不冲突。site_id 仅兼容旧字段，不再作为登录身份或授权依据。每秒复核会话，退出、禁用、重置密码或过期后终止已建立连接；首条 Hello 等待 10 秒，心跳间隔小于 60 秒。`CheckHealth` 保持只读且不占账号连接。旧手工签发的实例令牌不再用于接入。

平台目前未启用原生 TLS；生产应由可信网关提供 HTTPS/TLS，使密码和会话通过加密连接传输。本次不修改部署或验证线上网关。

## 兼容与验收

旧 `identities` 数据目录不会删除或自动转成普通账号，因为无法从随机实例令牌推导账号密码；管理员需要在新页面创建账号。旧页面、接口及手工令牌管理代码移除，数据库本身保留在原目录。

验收覆盖管理员创建/列表/修改/禁用/重置、密码哈希和重启持久化、重复用户名与并发版本、普通账号不能越权、正确/错误/禁用账号登录、过期/退出/改密撤销会话、多实例和真实断流清理。前端覆盖密码确认与清空、错误/冲突/草稿保护和页面主题。验证限本地平台与模拟客户端，不表示上位机客户端或现场联调完成。

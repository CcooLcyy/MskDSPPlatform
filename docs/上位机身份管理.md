# 上位机身份管理（第一版）

## 范围与使用方式

仅修改平台；在 `/agents` 提供管理页面，与点表、软件管理、平台维护共享导航、主题和管理员会话。沿用现有单管理员，管理员可以管理全部实例；本版不引入普通用户账号、多人授权、上位机端改造或远程业务操作。每个安装实例拥有平台分配的 UUID，名称和现场编号可以修改，身份不依赖现场操作员是否登录。

管理员登记名称、现场编号（可空）、备注后，平台生成实例身份和高熵接入令牌。令牌仅在登记/轮换成功响应中显示一次，平台只持久化 SHA256 摘要，不在列表、记录或日志返回明文。丢失令牌需要轮换。禁用阻止接入并断开已有会话；重新启用仍需有效凭据。撤销凭据不会恢复，必须轮换后才能再次接入。解绑清空现场、禁用并撤销凭据，保留身份和历史。

## 管理接口

管理 API 均要求现有管理员 cookie，未登录返回 JSON 401。写请求要求 `Content-Type: application/json` 和 `X-MskDSP-Action: agent-identity`，存在 Origin 时必须与 Host 同源；不开放 CORS。请求体上限 16 KiB。修改需要当前 `revision`，并发旧版本返回 409，不覆盖后提交的数据。

| 接口 | 输入 / 输出 |
| --- | --- |
| `GET /api/v1/agents` | 身份列表，包含实时在线状态，不包含凭据摘要 |
| `POST /api/v1/agents` | `{name,site_id,notes}`；201 `{agent,token}` |
| `GET /api/v1/agents/{id}` | 身份详情 |
| `PUT /api/v1/agents/{id}` | `{revision,name,site_id,notes,enabled}`；修改后的详情 |
| `POST /api/v1/agents/{id}/rotate` | `{revision}`；`{agent,token}`，旧凭据失效 |
| `POST /api/v1/agents/{id}/revoke` | `{revision}`；撤销后的详情 |
| `POST /api/v1/agents/{id}/unbind` | `{revision}`；解绑后的详情 |
| `GET /api/v1/agents/{id}/events` | 最近 100 条管理记录，包含操作者、操作和时间 |

名称为去除首尾空白后的 1～128 字节；现场编号最多 128 字节，备注最多 2048 字节；拒绝控制字符（备注允许换行）。实例上限 10000，列表最多返回这些身份。错误为 JSON `{error}`，400 输入错误、401 未登录、403 来源不合法、404 身份不存在、409 版本冲突、500 存储故障（不暴露数据库内部信息）。

## 接入协议

`AgentService.ConnectAgent` 使用 gRPC metadata `authorization: Bearer <token>`。首条 Hello 的 agent_id 必须对应已登记身份，site_id 必须与平台绑定一致，agent_version 最多 128 字节，protocol_version 必须匹配。缺失、重复或无效凭据均拒绝；不允许依靠自报 UUID、特殊前缀或现场编号绕过认证。

同一个实例只允许一条在线连接，不以新连接替换旧连接。首条消息等待最多 10 秒，心跳应小于 60 秒间隔；断流、取消、超时均清理会话。平台每秒复核身份，禁用、撤销、轮换或解绑后，现有连接最迟在下一次复核关闭；管理页面操作同时主动断开会话。现场绑定改变也会使旧连接失效。last_seen_at 记录最近一次成功接入或心跳，平台重启后身份和最后在线时间保留，在线状态重新建立。

`CheckHealth` 是独立的只读健康 RPC，供平台管理进程 `--probe-grpc` 使用，不认证实例、不创建会话，也不提供身份或业务数据。旧的匿名 Hello 接入不再可用。没有修改共享协议子模块和上位机客户端；后续客户端应按本文接入。平台当前未启用原生 TLS，生产接入要求由可信网关提供 TLS，使令牌通过加密连接传输；本次未验证生产网关配置。

双向 RPC 的客户端应同时关闭发送与接收两端。仅释放 HTTP/2 接收半流不等于取消完整连接；仍保留发送端但停止心跳的会话会在 60 秒超时后清理。

## 存储与验收

数据保存于平台数据根目录下 `identities/identities.sqlite3`，与现有数据目录解析规则一致。身份修改、凭据摘要更新和管理记录写入同一 SQLite 事务；数据库故障不回退为可匿名接入。备份应停止平台进程后复制整个 identities 目录。

验收覆盖登记/重启持久化、摘要存储、正确/错误身份认证、现场不匹配、版本冲突、撤销/禁用/轮换/解绑、来源校验、未登录拒绝、重复连接和断流清理。页面验证管理流程、一次性凭据展示、错误处理及主题与窄屏布局。这里的验证是平台端和模拟客户端验证，不代表上位机联调或现场验证。

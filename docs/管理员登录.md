# 管理员登录

首期提供单个管理员账号 `root`，登录后访问平台更新页面，并查看、检查和安装更新。
初始密码使用约定值，程序只内置带随机盐的 Argon2id 哈希，网页、日志及配置示例不含明文密码。

## 页面与接口

| 接口 | 语义 |
| --- | --- |
| `GET /login` | 登录页面；已有会话时跳转 `/update` |
| `GET /`、`GET /update` | 更新页面；未登录跳转 `/login` |
| `POST /api/v1/auth/login` | JSON `{ "username": "root", "password": "输入的密码" }`；成功返回 200 和管理员身份，并设置会话 cookie |
| `GET /api/v1/auth/me` | 返回 `{ "username": "root", "role": "admin" }`；会话缺失或过期返回 401 |
| `POST /api/v1/auth/logout` | 删除当前服务端会话并清除 cookie，返回 204；重复退出也成功 |
| `/api/update/status`、`/api/update/check`、`/api/update/apply` | 必须验证管理员会话；未登录返回 401，认证服务暂不可用返回 503，不执行更新 |

登录和退出请求必须设置 `Content-Type: application/json`、`X-MskDSP-Action: auth`。
更新操作沿用 `X-MskDSP-Action: update`。存在 `Origin` 时必须与公开 Host 同源；不开放 CORS。
错误使用 JSON `error` 提示，用户名和密码错误统一返回 401；每分钟最多 10 次登录尝试，超过后返回 429。
请求体限制 4096 字节，密码最多 1024 字节。不记录密码、密码哈希或 cookie。

会话使用随机生成的 cookie，仅保存在服务端内存；固定有效期默认 8 小时，最多 128 个会话。
cookie 设置 `HttpOnly`、`SameSite=Strict` 和 `Path=/`，不写入浏览器本地存储。
登录时更新当前 cookie，退出立即撤销。平台子进程重启、更新及回滚会使已有会话失效，需要重新登录。
页面收到 401 后停止更新操作并跳转登录。更新任务仍由管理进程执行。

## 配置

`[auth]` 可覆盖 `username`、`password_hash`、`secure_cookie`、`session_seconds`。
密码哈希必须是完整 Argon2id PHC 字符串；空密码或无效哈希拒绝启动。
有效期范围为 1～86400 秒。修改账号或密码配置后重启平台服务，旧会话同时失效。

运行 `mskdsp-platform --hash-admin-password`，通过标准输入输入新密码，输出可填入配置的随机盐哈希。
避免将密码作为命令行参数；不要提交本地密码配置。
本地 HTTP 调试使用 `secure_cookie = false`；对外部署使用 HTTPS 网关，并配置 `secure_cookie = true`。
管理进程代理保留公开 Host 和 Cookie，不使用客户端的转发头作为身份依据。

健康检查 `/healthz`、`/readyz`、版本 `/api/v1/version` 保持公开供运行时检查。
设备 gRPC 握手不使用网页管理员会话。本期不包含多用户、改密页面、设备身份认证或数据库持久化。

## 验收

- 正确凭据建立会话，错误用户名或密码不会得到 cookie；重复登录更换会话。
- 匿名、伪造、过期、重复 cookie 或退出后的会话无法访问管理页面和更新 API。
- 登录/退出跨源请求及缺少操作标记被拒绝；限流与请求长度限制生效。
- 更新管理进程验证 Cookie 后才执行操作；子进程不可用、非管理员身份或异常响应均拒绝执行。
- 前端覆盖失败提示、断网、重复提交、401 跳转和退出行为，保留已有更新/回滚测试。

## 启用及未验收项

- 当前功能默认关闭，现场未上线。启用步骤见 [总方案](远程设备接入与SSH隧道.md#启用步骤待获授权后部署)。
- 新远程访问要求 HTTPS；现有公网 HTTP 登录/软件地址未迁移，启用时须在登录设置配置实际 TLS 地址。HTTP 管理入口的 HTTPS 由网关提供。
- 终端当前支持 SSH 密码认证；现有高级配置的独立 SSH 升级流程不自动走平台隧道。
- 可选 mTLS 服务端可校验客户端 CA，但内置健康探测没有客户端证书身份，不能直接当作兼容现有更新自检的部署模式。
- 下位机 Linux x64 隔离编译测试已通过。首次运行发现测试注册没有复用隔离运行器、缺少 GTest 动态库路径，已修正 `test/CMakeLists.txt` 并重跑通过；不是把失败或零测试视为通过。尚未验证 ARM64、三端真机现场控制、公网部署、网络抖动和真实系统 SSH。
- 用户已确认无需额外排除，提交并同步四仓库。本轮提交按各仓库既有风格生成中文信息，使用 UTF-8 消息文件并校验原始提交对象；本报告不是部署完成或现场验收报告。

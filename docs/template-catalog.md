## 平台实现补充

`TemplateCatalog` 复用每次请求的 ClientAuth 会话检查，管理员与操作员均可读取；网页 Cookie 不作为凭据。目录沿用最多 1000 张模板的上限，输出有界字段。模板 JSON 限制为 10 MiB，gRPC 消息上限 12 MiB（目录总大小同样受此限制）。

SQLite schema v3 的 `template_history` 使用 `(id, revision)` 主键；创建、修改、删除、恢复均与当前记录变更处于同一事务。删除版本保留删除时的内容，但不在当前目录展示；即使回收站 90 天后清理，按 ID/版本查询历史仍可用。迁移仅回填现存当前/回收站版本，无法恢复升级前已被覆盖的版本。历史表禁止 UPDATE/DELETE，不提供历史清理接口。

验证覆盖真实本机 TCP gRPC（无凭据、网页 Cookie、重复 Bearer、管理员与操作员、退出、过期、账号撤销、当前/历史/删除读取、超过 tonic 默认 4 MiB 的模板）、完整 u64 版本精度、数据库迁移与重启、回收站清理后的历史保留、历史写入失败时创建/修改/删除/恢复回滚，以及历史表/保护缺失时拒绝启动。未进行远端部署或现场联调。
